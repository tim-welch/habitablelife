An atomic note is not a full argument. Where an atomic note is a single concrete thought, an argument is structured reasoning. Since an atomic note is one single thought, it can be used in any number of arguments as needed. The goal is to capture an idea in a way that makes it reusable and composable across different contexts. This allows our notes to be reused when building arguments without requiring all reuse to be the same argument.
