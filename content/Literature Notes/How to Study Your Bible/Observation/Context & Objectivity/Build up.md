The context of a passage matters when observing the text. The theme of each paragraph builds up to the theme of the chapter. Similarly, the chapter themes build up into a division theme, which then build up into the book theme. The theme of the Bible is built from the theme of each book. By paying attention to the theme of each of the pieces we gain a better understanding of the whole context in which the passage resides.

Paragraph -> Chapter -> Division -> Book -> Bible
