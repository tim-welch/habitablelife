# What an Atomic Note Is

Atomic notes are meant to be kept forever. They contain all relevant information in themselves, including references to sources and links to related notes. They express a single, fully developed idea and should be written in complete sentences as if someone else was going to read them, including future you. It is important that atomic notes capture the full, complete idea so that when returning to the note it contains everything needed to understand it. They are not reminders of thoughts or ideas; they _are_ the thoughts and ideas.
