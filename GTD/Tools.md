# Tools
### 1. **Use Todoist for quick capture + errands**

- Use mobile or web to quickly capture tasks: groceries, replies, deadlines
    
- Treat it as your **“inbox” or context-based list manager**
    

### 2. **Use Obsidian as your “Project Thinking System”**

- Write project notes, priorities, and GTD-style lists using markdown
    
- Use `- [ ]` tasks for compatibility with GPT
    
- Track daily/weekly reflections and sprint reviews in templates

#### Example
GPT-readable, Obsidian-friendly, and easy to maintain.
```
## 🗂 Projects
- [ ] Write June blog post (Next: Outline draft)
- [ ] Prepare Q3 planning doc (Next: Schedule team call)

## 🧠 Someday/Maybe
- [ ] Learn Tana or Capacities
- [ ] Build workout automation with GPT

## 🕑 Calendar Constraints
- Team sync: Tues 10am  
- Kid pickup: 4:30pm weekdays  
```
    

### 3. **Use GPT as your Coach + Planner**

- Paste your Obsidian note or section:
    
    > “Here’s my current Projects list and next actions (in markdown). Help me plan tomorrow.”
    
- Get output in clean markdown → paste it back into Obsidian
    
- You can say:
    
    > “Let’s do a retro. Here’s my sprint summary from Obsidian.”
