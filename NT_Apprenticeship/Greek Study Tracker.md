# 9. 🧭 Long-Term Greek Goals

Define goals by apprenticeship phases:

### Phase 0

- Learn alphabet & pronunciation
    
- Learn 30–50 high-frequency words
    
- Recognize basic verb forms
    
- Begin reading simple Greek phrases
    

### Phase 1

- Start reading Mark with tools
    
- Learn 100–150 total words
    
- Strong grasp of present and aorist
    
- Recognize participles in context
    

### Phase 2

- Vocabulary: 200–250 words
    
- Read short passages with fewer helps
    
- Grasp major syntactical markers in Matthew & Acts
    

### Phase 3

- Vocabulary: 300+ words
    
- Handle Pauline syntax
    
- Parse with more confidence
    

### Phase 4

- Recognize Johannine stylistic patterns
    
- Increased reading speed
    
- Comfort with dual meanings and symbolic language
    

### Phase 5

- Read key sections of Revelation with understanding
    
- Recognize Hebraisms in Greek
    
- Handle symbolic vocabulary
