## 🧱 Minimum Viable Week: Draft Structure

### 🗂️ Weekly Time Budget Assumptions

- Total available work hours: ~45 hrs/week
    
- Target for “MVW” coverage: ~30–35 hrs (leaves slack for interrupts)
### 🧩 By Role: Core Commitments

|Role|Essential Weekly Activities|Time Budget|When / How|
|---|---|---|---|
|**Scrum Master / Tech Lead**|Standups, retro, sprint planning, sprint review prep, management updates|8–10 hrs|Spread across week. Prep Mondays/Fridays|
|**Testing Lead**|1:1 test explanations, async Q&A with India, test review/coaching|5–6 hrs|Morning block overlap; async doc/record template|
|**Developer**|Code contribution, PR reviews, support other dev|8–10 hrs|Focus blocks; reduce to 1–2 key stories|
|**Backlog Manager**|Biweekly refinement, PO sync, story writing|3–4 hrs|PO sync Tues or Wed; refinement Thurs before sprint|
|**Strategic / Systemic**|Reflection, documentation, planning|2 hrs|Fri morning or Mon midday|

**Total: ~30–32 hrs protected time**
